# 安装 / 更新 wangmian-brain

1. 解压更新包，得到 `wangmian-brain/` 目录
2. 覆盖到：`~/.cursor/skills/wangmian-brain/`
3. **新开 Cursor Chat**，Skills 选 `wangmian-brain` 或口令 `$wangmian-brain`
4. 知识库仍依赖工作区：`src/resources/oneos-knowledge-base/`（含 `machine/kb-alias-index.tsv`）
5. 可选冒烟：`python3 ~/.cursor/skills/wangmian-brain/scripts/smoke-system-qa.py`
