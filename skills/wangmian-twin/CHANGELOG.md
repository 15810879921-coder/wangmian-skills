### 改动摘要

| 主题 | 改动 |
|---|---|
| 大脑裁决 | 规则/需求须对照 KB+现网逻辑：冲突或不合理 → 说明原因驳回；合理 → 直接执行并回报结果 |
| Codex MD | **先判题再出 MD**：仅「研发经 Codex/Cursor」且「业务规则 / 能不能做」时才人话+AI 可读 MD；本尊聊方案/产线/能力建设默认不出 |
| 拉式知识 | 灌文件/录音/文字 → 可行性与业务模式评估 → 反问补齐 → 按闭环/产品线/规划/合规/溯源沉淀 |
| 双门禁 | **G1** 合理性/紧迫性（分身+大脑）；**G2** 越权/红线/写主库须工单·责任人+领导审批（防截图改业财红线） |
| 总控位 | 分身坐**业务总控调度**（边界、路由、规则弹药）；外部数字人/Worker 为执行层，卡住问分身 |
| 发版评估 | 可评估「发版能否自动化」：流水线可自动，担责不可自动 → 受控 CD（审批令牌）；非研发问规则时不出规程 MD |
| 表结构/副作用 | **本期不做**字段级承诺；待开发喂代码/库/数据字典后再升级 |
| 分发 | `install.sh` 一键装到 Cursor + Codex；仓库 `15810879921-coder/wangmian-skills` |
